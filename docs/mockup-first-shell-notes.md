# Mockup-first shell implementation notes

The approved PawPath mockup is the visual reference for this increment. Its visual patterns are mapped only to real PawPath preparedness functions.

The shell uses the existing logo, cream/forest/amber palette, editorial serif hierarchy, prominent Plan/Care Now actions, four quick-action cards, and a mobile-first stacked hero. Fictional mockup functions such as walk tracking, journals, social/community, and park discovery are intentionally excluded.

The decorative hero landscape is CSS-built in this increment so the repository does not depend on unlicensed stock imagery or a new external image service. A future curated demonstration-data increment can replace that decorative treatment with an approved original PawPath adventure asset without changing the shell structure.
